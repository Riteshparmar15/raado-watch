# RAADO WATCH — Beginner Web Project

A clean, responsive luxury watch brand landing page built for learning foundational front-end web development and preparing for Open Knowledge Format (OKF) documentation.

> **Important Notice:** RAADO WATCH is a 100% fictional brand created strictly for educational purposes. It has no affiliation with any existing watch maker.

---

## Project Structure

```text
RAADO/
├── index.html       # Semantic structure and accessible markup
├── styles.css       # Vanilla CSS styling, light luxury theme, responsive layout
├── script.js        # Product catalog data, modal interaction, form handling
├── assets/
│   └── images/      # Curated local imagery (hero-watch, classic, sport, minimalist)
└── README.md        # Project guide and documentation
```

---

## Features

- **Semantic HTML5**: Organized with `<header>`, `<section>`, `<article>`, and `<footer>` tags.
- **Pure Vanilla CSS**: Responsive CSS Grid and Flexbox with a refined, light luxury color palette.
- **Interactive JavaScript**: Modal popup for product details, keyboard accessibility (Esc key to close), and mobile hamburger navigation.
- **Zero External Dependencies**: Runs directly in any modern browser without build steps, node modules, or external databases.

---

## How to Run

1. Open `index.html` directly in any web browser, or
2. Use a local development server (e.g., Python `http.server` or VS Code Live Server).
